# Onde Estou? 📍

Página que usa a **API de Geolocalização** do navegador para descobrir onde você está e mostrar sua posição num mapa feito com [Leaflet](https://leafletjs.com/) e OpenStreetMap.

## Como usar

1. Abra o `index.html` no navegador.
2. Clique em **Encontrar Minha Localização**.
3. Permita o acesso à localização quando o navegador pedir.

## Arquivos

- `index.html`: estrutura da página
- `style.css`: estilos
- `script.js`: pega a localização e monta o mapa
